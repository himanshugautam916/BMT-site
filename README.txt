ABC Towing GitHub Pages starter website

1. Upload all files to your GitHub repository.
2. Keep the repository public.
3. Enable Settings > Pages > Deploy from a branch > main > /root.
4. Replace placeholder phone, email, service area and company text.
5. Upload truck photos later and replace the hero placeholder in styles.css.
6. The top navigation is fixed/sticky, and the CONTACT button stays available on every page.
